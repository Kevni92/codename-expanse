## Architecture Decision Records

See [`adr/README.md`](adr/README.md).

When adding architecture:
1. copy [`../templates/architecture.md`](../templates/architecture.md);
2. link every implemented concept;
3. define concrete units, formulas, ownership, contracts, validation, performance and tests;
4. add it to this index;
5. create an ADR for durable cross-cutting decisions;
6. keep status below `Approved` until explicitly approved.
