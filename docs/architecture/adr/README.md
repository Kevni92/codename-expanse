# Architecture Decision Records

ADRs record durable technical decisions and their consequences.

Use [`../../templates/adr.md`](../../templates/adr.md).

Recommended numbering: `ADR-0001-short-title.md`, incrementing monotonically.

An ADR should be created when a decision is cross-cutting, difficult to reverse, establishes a project-wide constraint, or deliberately supersedes an earlier architectural rule.
